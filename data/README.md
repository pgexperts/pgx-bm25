# data/

Third-party corpus data vendored for `sql/57_ranking_quality.sql` (the gated
NDCG@10 regression suite). Everything here is loaded read-only by that suite
via `\copy`; nothing here is generated by this project.

## scifact_*.data — BEIR SciFact

Byte-for-byte renamed copies of three files from BEIR's SciFact release —
`corpus.jsonl` (5,183 lines), `queries.jsonl` (1,109 lines — BEIR bundles the
train and test splits in one file; only the 300 ids referenced by
`qrels/test.tsv` are the canonical test-query set), and `qrels/test.tsv`
(339 judgment rows + header). No reformatting: the bytes are unchanged so
they stay checkable against the upstream artifact below.

- `scifact_corpus.data` = `scifact/corpus.jsonl`
- `scifact_queries.data` = `scifact/queries.jsonl`
- `scifact_qrels.data` = `scifact/qrels/test.tsv`

**Source:** `https://public.ukp.informatik.tu-darmstadt.de/thakur/BEIR/datasets/scifact.zip`
**Zip md5:** `5f7d1de60b170fc8027bb7898e2efca1`

**License / attribution:** SciFact claims, queries, and qrels are CC BY 4.0
(Wadden et al., AllenAI). The underlying paper abstracts are ODC-By 1.0
(S2ORC, Allen Institute for AI). Both are attribution-only licenses;
redistribution here is permitted with attribution, given above.

**Why vendor verbatim instead of a derived/trimmed file:** a derived artifact
would need re-justifying every time someone asks "is this really the
official corpus" — an md5-checkable byte-for-byte copy answers that
question once. The suite does its own filtering (train/test split, id
casts) at load time in SQL, not at vendoring time.

### Re-vendoring procedure

If BEIR ever republishes this dataset (fixed line, new split, etc.), redo
the full chain rather than patching in place:

```sh
curl -fLO https://public.ukp.informatik.tu-darmstadt.de/thakur/BEIR/datasets/scifact.zip
md5 scifact.zip   # must equal 5f7d1de60b170fc8027bb7898e2efca1 -- stop on mismatch
unzip scifact.zip
cp scifact/corpus.jsonl      data/scifact_corpus.data
cp scifact/queries.jsonl     data/scifact_queries.data
cp scifact/qrels/test.tsv    data/scifact_qrels.data
cmp scifact/corpus.jsonl     data/scifact_corpus.data
cmp scifact/queries.jsonl    data/scifact_queries.data
cmp scifact/qrels/test.tsv   data/scifact_qrels.data
```

The three `cmp` calls must report no differences before committing — that is
the byte-identity proof this directory relies on in place of a checksum
manifest.
